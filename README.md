# 🚀 Agente de Vagas e Adequação de Currículo (AI-Driven ATS)

Agente autônomo em Python 3.10+ projetado para buscar/analisar vagas de Tecnologia (Backend, Trainee TI, Automação, Mainframe), calcular a pontuação de aderência (match ATS) usando a API gratuita da **Groq** (`llama-3.3-70b-versatile`), gerar um currículo customizado e otimizado para ATS em formato PDF via **ReportLab**, salvar o histórico no **Supabase** (PostgreSQL) e disparar notificações HTML com anexo via **Gmail SMTP**.

---

## 🏗️ Arquitetura do Repositório

```text
agente-vagas-ia/
├── .github/

│   ├── __init__.py

├── master_profile.json        # Perfil profissional mestre em JSON (verdade do candidato)
├── main.py                    # Script principal / orquestrador do pipeline
├── requirements.txt           # Dependências do projeto
├── .gitignore                 # Arquivos ignorados pelo Git
└── README.md                  # Documentação do projeto
```

## 🛠️ Stack Tecnológica

- **Linguagem:** Python 3.10+
- **LLM Engine:** Groq API (`groq` SDK em Python - 100% Gratuito)
- **Gerador de PDF:** ReportLab (`reportlab`)
- **Banco de Dados:** Supabase (`supabase`)
- **Notificador:** Python Native `smtplib` + `email.mime` (Gmail App Password)
- **Orquestração CI/CD:** GitHub Actions (`cron`)

## 🗄️ Estrutura da Tabela no Supabase (SQL DDL)

Crie a seguinte tabela no seu projeto Supabase no editor SQL:

```sql
CREATE TABLE vagas_processadas (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    titulo_vaga TEXT NOT NULL,
    empresa TEXT,
    link_vaga TEXT,
    match_score INT,
    justificativa TEXT,
    resumo_adaptado TEXT,
    status_candidatura TEXT,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT TIMEZONE('utc'::text, NOW()) NOT NULL
);

-- Se a tabela já existir, execute o comando de alteração abaixo:
ALTER TABLE vagas_processadas ADD COLUMN IF NOT EXISTS status_candidatura TEXT;
```

## 🚀 Como Executar Localmente

1. **Clone o repositório e acesse a pasta:**
   ```bash
   git clone https://github.com/seu-usuario/agente-vagas-ia.git
   cd agente-vagas-ia
   ```

2. **Crie e ative um ambiente virtual:**
   ```bash
   python -m venv .venv
   # No Windows:
   .venv\Scripts\activate
   # No Linux/macOS:
   source .venv/bin/activate
   ```

3. **Instale as dependências:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Execute o agente:**
   ```bash
   python main.py
   ```

## 🛡️ Garantias de Qualidade ATS
- **Zero Alucinação:** O gerador de conteúdo limita-se estritamente ao histórico factual registrado em `master_profile.json`.
- **Layout Limpo:** O PDF gerado por `pdf_generator.py` prioriza hierarquia simples de texto, sem tabelas complexas ou layouts que dificultem a leitura por robôs de recrutamento (ATS).
